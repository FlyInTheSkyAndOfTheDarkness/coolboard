# CoolBoard

Личная клавиатура для iPhone: свайп-набор, восемь языков, Т9, подсказки и личный словарь, эмодзи Apple, GIF, стикеры, перевод, поиск, голосовой ввод в приложении, буфер фрагментов, темы и фотофон, режим одной руки, размер клавиш и ряд цифр. Целевое устройство — iPhone 11 с iOS 26.2. Минимальная версия проекта — iOS 16.

Основной образец интерфейса — [Gboard для iPhone](https://apps.apple.com/us/app/gboard-the-google-keyboard/id1091700242): светлая серая подложка, белые клавиши одинаковой ширины, отступы буквенных рядов, цифровые подсказки сверху, синий ввод, широкий пробел и нижняя строка переключения языков. Тема **«Gboard · светлая»** используется по умолчанию для новой установки; ранее выбранная тема сохраняется, её можно сменить через ⚙. Пробел показывает название языка; свайп по нему двигает курсор, обычное нажатие вставляет пробел. Цифра в углу буквы доступна через удержание с выбором на iPhone / правую кнопку мыши в предпросмотре. Эмодзи на iPhone остаются системными Apple. Это собственное приложение CoolBoard, с собственным кодом и словарным движком.

Здесь два отдельных запуска: настоящее расширение iOS на Swift / UIKit / SwiftUI и браузерный предпросмотр для Windows / Ubuntu. Раскладки у них общие, реализация ввода и хранилища отдельные. Браузер проверяет интерфейс и логику макета, но не проверяет расширение iOS.

## Проверить на Windows

Дважды нажми `start-preview.cmd` и открой http://localhost:4173. Нужен Node.js 22+. Установка npm-пакетов для самого предпросмотра не нужна.

Или в терминале:

```powershell
npm.cmd start
```

На Ubuntu: `npm start`. Сервер слушает только этот компьютер. В браузере доступны ввод в позиции курсора, языки, Т9 на локальном словаре, подсказки, личный словарь, эмодзи с поиском и недавними, фрагменты, темы и настройки. Копирования в этой вкладке автоматически попадают в историю; текущий буфер других приложений автоматически читается только после разрешения браузеру и пока вкладка видима и активна. Кнопка «Разрешить чтение буфера» запрашивает доступ, а не требует вручную добавлять каждый текст. Браузерные данные сохраняются в localStorage этого браузера и не переносятся на iPhone. На Windows эмодзи рисует Windows; на iPhone — iOS. Картинки эмодзи и шрифты Apple в проект не копируются.

## Языки, Т9 и эмодзи

В ⚙ включай и выключай языки: қазақша, русский, English, українська, Deutsch, Türkçe, français, español. По умолчанию активны ҚАЗ / РУС / ENG. Кнопка языка переключает только активные раскладки. Последний язык удалить нельзя. В iOS удержание кнопки языка открывает список для прямого выбора; в браузере правая кнопка мыши открывает настройки языков. Это встроенный каталог восьми раскладок; скачивание произвольных новых языков не реализовано.

**Т9** означает автокоррекцию обычного буквенного ввода. Переключатель **Т9** на панели и переключатель в ⚙ управляют одной настройкой. **Подсказки слов** включаются независимо. Исправление происходит при пробеле, переводе строки и знаках препинания только для слова, которое набрано этой клавиатурой. Нажми **«Вернуть»** после замены или первым нажатием удаления восстанови исходное слово. Выбор подсказки вставляет слово и пробел. Кнопка книги с плюсом запоминает слово для выбранного языка, до 500 слов на язык; такие слова не исправляются автоматически. Слова в адресах, ссылках, идентификаторах, выделениях и при редактировании внутри слова не заменяются.

В нативной версии работает `UITextChecker` для доступных системе языков плюс локальные словари: **46 681 слово** в восьми языках, в том числе **4 681 казахское**. Свайп-декодер сопоставляет траекторию с формой слова на текущей раскладке и предлагает до трёх вариантов. Двойные буквы распознаются по словарю. Подсказки следующего слова основаны на небольшом наборе частых сочетаний; это не языковая модель Gboard. Смешанный ввод добавляет дополнения из других включённых языков без смены раскладки. Морфологического разбора казахского нет; качество свайпа и исправлений отличается от Google и Apple. Автоматическое накопление истории набранных слов не выполняется; личные слова сохраняются по явному нажатию.

Нажми **▦ «Все инструменты»** на панели клавиатуры.

| Функция | Реализация и условия |
| --- | --- |
| Свайп-набор | Реальное распознавание траектории по локальному словарю, восемь раскладок. Включается в ⚙. Это собственный базовый декодер, не закрытый движок Google. |
| Следующее слово | Контекстные подсказки для частых сочетаний, отдельный переключатель. |
| Смешанные языки | Дополнения из активных словарей; без автоматической смены алфавита. |
| Голос | В приложении iOS: **«Голос» → запись → копировать → вернуться в чат**. В браузере — Web Speech API, если поддерживается. Языки и качество зависят от Apple / браузера. |
| Перевод внутри клавиатуры | MyMemory, включение онлайн-функций и полный доступ; до 500 байт за запрос, действуют лимиты провайдера. Запрос отправляется только по кнопке, перевод вставляется отдельным нажатием. |
| Поиск внутри клавиатуры | Wikipedia: результаты и вставка выбранной ссылки. В приложении экран **«Поиск»** открывает настоящий Google Search / Google Translate в Safari. В браузере есть ссылка на Google. |
| GIF | Поиск в Wikimedia Commons и свои файлы. Каталог отличается от Tenor/GIPHY. На iOS — копирование оригинального GIF → «Вставить» в чате. В браузере — скачивание GIF / вставка ссылки. До 3 МБ на файл. |
| Стикеры | Локально создаваемые прозрачные PNG с фразами, плюс свои PNG/JPEG/GIF. На iOS копируются в буфер; в браузере — копирование PNG или скачивание при запрете Clipboard API. Это собственные стикеры, не лицензированные наборы Google. |
| Текстовые смайлики | Kaomoji и обычные текстовые смайлы вставляются как текст. |
| Своя медиабиблиотека | До 12 файлов и 6 МБ. На iOS: приложение **«Файлы» → выбрать → вернуться в клавиатуру → «Стикеры» → «Из буфера»**. Удаление файлов доступно. |
| Режим одной руки | Слева / справа / обычная ширина, сохраняется; стрелка в боковом поле возвращает полную ширину. |
| Фотофон | В iOS из скопированной картинки через ⚙; в браузере загрузка своего фото. Фото остаётся локальным. |
| Виброотклик | Отдельный переключатель. На iPhone требует полного доступа; в браузере зависит от Vibration API устройства. |
| Редактирование | Курсор, копирование выделенного, удаление слова, отмена последней вставки в iOS. В браузере — история своих правок до 60 шагов. iOS не даёт произвольно управлять выделением текста приложения. |

Онлайн-функции **по умолчанию выключены**. Их включение и нажатие «Перевести» / «Найти» — отдельные действия. Поисковый запрос и текст перевода передаются соответствующему провайдеру; весь набираемый текст автоматически не отправляется. Ошибки сети, лимиты и неподдерживаемые языки показываются в панели, а не вставляются в поле чата. Неактуальные ответы отменяются при переходе к другому инструменту.

Расширению клавиатуры iOS [не даёт доступ к микрофону](https://developer.apple.com/documentation/uikit/configuring-open-access-for-a-custom-keyboard). Запись реализована в основном приложении через Speech и AVFAudio Apple, с системными разрешениями и остановкой при закрытии экрана / уходе в фон. CoolBoard не сохраняет аудиофайлы; Apple может обрабатывать звук на сервере, если локальная модель недоступна. Закрытый движок Gboard, его облачные модели, Memoji и фирменные стикер-паки не копируются. Memoji и системная диктовка доступны через клавиатуру Apple (🌐).

Кнопка **😀** открывает каталог Unicode 16.0: **3 781 символ и сочетание**, девять категорий, поиск по названиям на русском, казахском и английском, 32 недавних, пять оттенков кожи и стандартный вариант. Удержание эмодзи на iPhone / правая кнопка мыши в браузере открывает доступные варианты, включая сочетания оттенков. Вставляются Unicode-символы, на iPhone они отображаются системным шрифтом Apple. Собственные изображения и шрифты не подставляются.

В расширении iOS для поиска нажми **«Найти эмодзи»** или **«Найти фрагмент»**, введи запрос нашей клавиатурой и нажми **«Готово»** / ввод. Запрос остаётся внутри панели и не попадает в приложение. Настоящую системную клавиатуру **«Эмодзи»**, Memoji и стикеры можно открыть через **🌐**, если они добавлены в настройках iPhone. Панель CoolBoard не встраивает закрытый интерфейс Apple.

## Получить IPA без собственного Mac

В репозитории подготовлен GitHub Actions workflow **Build iPhone IPA**. Он использует облачный macOS с Xcode, проверяет нативную библиотеку фрагментов, генерирует Xcode-проект через XcodeGen, собирает приложение с расширением и упаковывает **неподписанный** `CoolBoard-unsigned.ipa`.

1. Создай свой приватный репозиторий GitHub и загрузи туда содержимое этой папки, включая `.github`. Приватность не обязательна технически, но подходит личному проекту.
2. Открой **Actions → Build iPhone IPA → Run workflow**.
3. После успешной сборки скачай artifact **CoolBoard-unsigned** и распакуй ZIP. Внутри будет `.ipa`.
4. Подпиши и установи его через AltStore Classic с Windows по инструкции ниже.

Загрузка на GitHub и запуск облачной сборки автоматически из этой папки не выполняются. Проверь доступный лимит Actions и условия оплаты macOS runners в своём GitHub-аккаунте. Apple ID и сертификаты для сборки неподписанного IPA не нужны. Пароли и сертификаты в репозиторий не добавляй.

## Установить на iPhone с Windows

Файл `.ipa` нельзя установить обычным открытием в «Файлах». Приложение и его `.appex` должны быть подписаны для устройства.

1. Установи **AltServer / AltStore Classic** по [официальной инструкции для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Используй ссылки на компоненты Apple из этой инструкции.
2. Подключи iPhone кабелем, подтверди доверие компьютеру, установи AltStore через AltServer. Apple ID вводится только в установленный инструмент, не в этот проект и не в чат.
3. Если iOS попросит, подтверди доверие разработчику в **Настройки → Основные → VPN и управление устройством** и включи **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Может понадобиться перезагрузка.
4. Передай `.ipa` на iPhone, например через iCloud Drive. В AltStore открой **My Apps → ＋** и выбери IPA.
5. Если установщик предложит удалить расширения (**Remove App Extensions**), выбери **Keep App Extensions**: без `CoolBoardKeyboard.appex` клавиатура работать не будет.
6. Открой CoolBoard и выполни шаги подключения клавиатуры в приложении.

Бесплатный аккаунт требует [обновления подписи каждые 7 дней](https://faq.altstore.io/altstore-classic/your-altstore). AltStore может обновлять её через AltServer; Windows-компьютер должен быть доступен. У Apple есть ограничения на число приложений и App IDs; расширение клавиатуры занимает дополнительный App ID. Сохраняй одни идентификаторы и аккаунт при обновлении; не удаляй приложение, если хочешь сохранить библиотеку.

Названия пунктов iOS и AltStore могут отличаться в зависимости от языка и версии. Установка и полный доступ расширения требуют проверки на самом iPhone; предпросмотр на Windows их не подтверждает.

## Как работает буфер

- **История пополняется автоматически и хранит последние 10 разных скопированных текстов**, до 10 000 единиц UTF-16 каждый. Новый текст вытесняет самый старый; наблюдаемое повторное копирование поднимает существующую запись наверх без дубликата.
- **Скопировать текст → открыть CoolBoard → ▤ → нажать нужную запись для вставки**. Нажимать «Сохранить скопированное» для обычного пополнения истории больше не нужно. При открытии клавиатуры подхватывается текущее содержимое буфера; пока она видна, изменения отслеживаются через уведомления UIPasteboard и проверку changeCount раз в 0,8 секунды. Повторная проверка без изменений не читает текст заново.
- **Ограничение iOS:** расширение не работает как постоянный фоновый диспетчер буфера. Если при закрытой клавиатуре скопировать A, затем B, затем C, при её открытии доступен только C. Восстановить A и B из системного буфера нельзя. История содержит последние десять текстов, которые клавиатура смогла получить, а не гарантированно каждое системное копирование. [Apple — UIPasteboard](https://developer.apple.com/documentation/uikit/uipasteboard), [changeCount](https://developer.apple.com/documentation/uikit/uipasteboard/changecount).
- Для автоматического чтения расширению нужен **полный доступ**; iOS может отдельно спросить разрешение вставки. При отказе автопроверки не повторяют запрос постоянно: после разрешения можно нажать «Повторить доступ». Набор и сохранённые записи работают без полного доступа. В ⚙ автосохранение можно выключить.
- Можно выделить текст в приложении и нажать **text.badge.plus** на панели клавиатуры — сохранить выделенное без чтения общего буфера, если приложение отдаёт выделение через iOS API.
- **Закреплённые фразы хранятся отдельно**, до 100, во вкладке «Закреплённые». Они не занимают места в последних десяти копированиях и не могут блокировать новое копирование. Когда закреплённый текст стареет, он исчезает из истории, сохраняясь в закреплённых. Очистка истории оставляет закрепления. Старая библиотека из 100 записей автоматически мигрирует в десять последних плюс закреплённые.
- Удалённая запись не появляется снова от простого открытия клавиатуры с тем же буфером. Для этого хранится SHA-256 отпечаток последнего прочитанного текста, без отдельной скрытой копии самого текста. Новое наблюдаемое копирование того же текста снова может добавить его в историю.
- Фрагменты, словари, настройки и картинки хранятся в sandbox расширения. App Groups, собственного сервера и аналитики нет. Обычный набор работает офлайн; опциональные онлайн-инструменты выполняют явные запросы к MyMemory и Wikimedia. Настройки меняются через ⚙ клавиатуры. Контейнерное приложение содержит инструкцию, тестовое поле, запись голоса, импорт файлов и поиск Google в Safari.

## Текущие ограничения

Нет облачной синхронизации, произвольной установки новых языковых IME и рукописного ввода. Доступны восемь раскладок, а не весь каталог языков Gboard. Раскладка ҚАЗ — своя: отдельный ряд **ә і ң ғ ү ұ қ ө һ**, ниже полный кириллический набор. Движки, сервисы и словари собственные / открытые; полная идентичность Gboard не заявляется. Google Search и голос доступны в основном приложении, inline-поиск в расширении — Wikipedia. Автоматической отправки GIF/стикера в чат нет: на iOS нужно нажать «Вставить». Пользователь может выбрать пять палитр или своё фото, три размера и ряд цифр. Нативную часть требуется собрать и проверить на iPhone; браузерные тесты этого не подтверждают.

Сторонняя клавиатура не появляется в защищённых полях и некоторых телефонных полях; приложения могут запретить её. Подробности: [Apple — Custom Keyboard](https://developer.apple.com/library/archive/documentation/General/Conceptual/ExtensibilityPG/CustomKeyboard.html). Apple iOS Simulator и нативная сборка требуют [macOS и Xcode](https://developer.apple.com/xcode/system-requirements/).

## Проверки разработки

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run test:browser
```

Браузерные тесты используют установленный Google Chrome через Playwright. На системе без Chrome установи его или замени `channel: 'chrome'` в `playwright.config.js` и установи Chromium: `npx playwright install chromium`.

Нативные тесты библиотеки и декодирования общих раскладок запускаются в macOS workflow перед сборкой. На Mac вручную:

```sh
swiftc ios/Shared/ClipLibrary.swift ios/Shared/KeyboardData.swift ios/Shared/TextInputRules.swift ios/Shared/GlideDecoder.swift ios/Tests/main.swift -o /tmp/coolboard-tests
/tmp/coolboard-tests shared/layouts.json shared/lexicon.json shared/emoji.json shared/prediction.json
brew install xcodegen
bash scripts/build-ios.sh
```

Для запуска в Xcode: `cd ios && xcodegen generate`, затем открыть `CoolBoard.xcodeproj`. Для установки из Xcode выбери свою Team у обоих targets и уникальную пару Bundle IDs с общим префиксом. Для Simulator подпись не нужна; после установки включи расширение в настройках симулятора.

Перед ежедневным использованием проверь на iPhone портрет и альбом, 🌐, добавление и отключение языков, Т9 включён/выключен, отмену автозамены, подсказки и личный словарь, поиск и вставку эмодзи, оттенки, удаление составного эмодзи, удержание удаления, полный доступ включён/выключен, фрагменты после перезапуска, темы и обновление подписи без удаления приложения.

Каталог эмодзи генерируется командой `python scripts/generate-emoji.py` из [Unicode 16.0](https://unicode.org/Public/emoji/16.0/emoji-test.txt) и аннотаций [CLDR 46](https://github.com/unicode-org/cldr/tree/release-46/common/annotations). Генератору нужен интернет; сама клавиатура использует готовый локальный JSON. Лицензия данных — `third_party/unicode/LICENSE.txt`; она включается в ресурс расширения. Изображения эмодзи не скачиваются.

Словари свайпа генерируются `python scripts/generate-prediction.py` из [FrequencyWords / OpenSubtitles 2018](https://github.com/hermitdave/FrequencyWords), с фиксацией commit в JSON, фильтрацией под раскладки и ограничением 6 000 слов на язык. Изменённые словарные данные распространяются по **CC BY-SA 4.0**; атрибуция и полный текст лицензии находятся в `third_party/frequencywords` и включаются в приложение. Эта лицензия данных не распространяется на отдельно написанный код приложения. Внешние сервисы: [MyMemory API](https://mymemory.translated.net/doc/spec.php), [лимиты MyMemory](https://mymemory.translated.net/doc/usagelimits.php), [MediaWiki API](https://www.mediawiki.org/wiki/API:Main_page).
